# 全面拥抱Sing-box
辅助文件，包括：
1. [singbox_12.json](https://github.com/lifeexplore/OpenClash-Auxiliary-Files/blob/openclash-auxiliary-files/singbox_12.json)：sing-box转换控制文件
2. [singbox_self.json](https://github.com/lifeexplore/OpenClash-Auxiliary-Files/blob/openclash-auxiliary-files/singbox_self.json)：带自建节点的sing-box转换控制文件
3. [ipone_11.json](https://github.com/lifeexplore/OpenClash-Auxiliary-Files/blob/openclash-auxiliary-files/iphone_12.json)：iphone的sing-box转换控制文件
4. [iphone_self.json](https://github.com/lifeexplore/OpenClash-Auxiliary-Files/blob/openclash-auxiliary-files/iphone_self.json)：带自建节点的iPhone，sing-box转换控制文件
5. [blacklist.json](https://github.com/lifeexplore/OpenClash-Auxiliary-Files/blob/openclash-auxiliary-files/blacklist.json)：补充黑名单
6. [blacklist.list](https://github.com/lifeexplore/OpenClash-Auxiliary-Files/blob/openclash-auxiliary-files/blacklist.list)：Mihome补充黑名单


说明：
1. OpenWrt sing-box版本1.12
2. iPhone sing-box版本1.11
3. 旁路由模式
4. 订阅转换服务地址：选择的是Docker的[sing-box-subcribe](https://github.com/Toperlock/sing-box-subscribe)
