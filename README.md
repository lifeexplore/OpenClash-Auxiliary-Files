# OpenClash-Auxiliary-Files
OpenClash的辅助文件，包括：
1. ACL4SSR.ini：自定义模板
2. addition.list：Proxy补充站点
3. Setup Screenshots：设置截屏

说明：
1. 基于OpenWrt
2. OpenClash版本：alpha-smart-gd794302
3. 旁路由模式
4. 自定义模板地址：https://raw.githubusercontent.com/lifeexplore/OpenClash-Auxiliary-Files/refs/heads/openclash-auxiliary-files/ACL4SSR.ini
5. 订阅转换服务地址：选择的是Docker的本地转换，可以选择不同的转换

	如何需要在Docker安装转换，请参考：
		https://github.com/asdlokj1qpi233/subconverter
6. 未截图的不需要设置
